# Benchmark strategy

回归体系使用仓库自建、固定种子的合成小数据，不复制受版权保护赛题，也不把 fixture 结果当成真实竞赛能力。案例只要求自动验证关键数值范围和结构结果，不写死完整论文。

指标分三层：硬性失败项不能被总分抵消；质量项按 100 分记录 PDF 页数、空白页、缺图、乱码和溢出；警告项保留人工逐页视觉验收、单次 smoke 未做复现等非阻断边界。伪造结果检查采用“真实非零/零退出证据 + 输入与结果哈希 + 结构化 claim 映射 + 独立数值范围验证 + 第二次复现”的可审计组合，不声称能证明任意程序不存在恶意伪造。

Reviewer 在单独子进程中读取落盘产物副本，只向副本的 `review/` 写入；主 attempt 前后哈希必须一致。这是工作流级隔离，不冒充操作系统安全沙箱。
